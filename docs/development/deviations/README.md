# Engineering deviations

The [0.1.0 development-only timing exception](development-timing.md) and the separately scoped [0.1.1 development-only timing exception](development-timing-0.1.1.md) apply only to their named prerelease versions. Neither waives correctness, safety, allocation, or other evidence requirements. Any later deviation must state its affected rule, exact scope, technical reason, user impact, compensating controls, accountable owner, evidence and review or expiry date; an absent record is not an approval.
