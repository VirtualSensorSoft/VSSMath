# Contributing

Contributions are reviewed through GitHub pull requests. Keep changes focused,
explain their observable behavior, and include relevant tests and documentation.

The initial repository bootstrap does not yet contain library source or the
project's complete build and numerical guidance. Those materials will be added
in a separately reviewed foundation change. Do not include credentials, local
machine paths, private data, generated build trees, or unreviewed performance
claims.

No contribution receives a reuse license through submission. See [LICENSE](LICENSE).
